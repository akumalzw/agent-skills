## 结构与内容

- 总览具有基线、范围、排除项、覆盖状态及导航；占位符已填实或明确未知。
- 场景和物理合并组织，每个场景包含条件、部署、实例、配置、路径、代码关联、验证及缺口；共享定义在场景内有明确适用绑定。

## 证据与关联

- 关键结论的 E-* 存在，来源位置和基线可定位；未提交内容未冒用 HEAD 永久链接。
- SC-* → 部署与 RI-* → 配置 / 入口 / 分支 → MOD-* / ARCH-* / DD-* → 代码 / E-* 可追溯；反向能找到受影响场景。
- 架构契约与详细实现一致；无法解析的外部或动态边界明确说明。
- 图和正文的组件、实例、关系与条件一致，类、线程、进程及节点未混淆。
- 源码事实、声明、现场确认、推断、未知和冲突分别呈现。规范、建议、现状不混写。
- 现场结果具有环境、时间和版本；缺失时不标成当前已验证。

## 文件与安全

- 所有本地资源和页面引用可达；跨页 ID 有定义，无重复定义或悬空引用。
- 文件未泄露凭据、隐私或业务敏感原文；未覆盖人工修改。
- 未运行构建、测试或渲染时明确未验证；未执行发布时不宣称上线。
